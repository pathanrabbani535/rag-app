# 🚀 Professional RAG Application

A high-performance Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and chat with them using LLMs.

## ✨ Features
- 📄 **Multi-PDF Upload**: Drag-and-drop multiple PDFs for indexing.
- 🧠 **Semantic Search**: Powered by `Sentence Transformers (all-MiniLM-L6-v2)` and `FAISS`.
- 🤖 **Context-Aware Q&A**: Answers generated by OpenAI GPT-4o based on retrieved document chunks.
- 🔍 **Source Attribution**: Every answer includes citations with the exact text and document name.
- 🌓 **Modern UI**: Fully responsive React interface with Dark/Light mode and typing animations.
- 💾 **Session Persistence**: Chat history is saved locally.

## 🛠️ Tech Stack
- **Backend**: FastAPI, LangChain, FAISS, PyPDF, Sentence Transformers.
- **Frontend**: React, TypeScript, Tailwind CSS, Zustand.
- **LLM**: OpenAI GPT-4o.

## 🚀 Installation & Setup

### Backend
1. Navigate to the backend folder:
   ```bash
   cd backend
   ```
2. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Create a `.env` file in `backend/` and add your OpenAI API key:
   ```env
   OPENAI_API_KEY=your_openai_api_key_here
   ```
4. Start the server:
   ```bash
   python app/main.py
   ```

### Frontend
1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🌐 Deployment

### Backend (Render/Railway)
- Use a Dockerfile (provided in the repo) or connect your GitHub repo to Render.
- Ensure `OPENAI_API_KEY` is set in the environment variables.
- Add a persistent disk mount for the `backend/data` folder to save the FAISS index.

### Frontend (Netlify/Vercel)
- Connect your GitHub repo to Netlify.
- Set the build command to `npm run build` and the output directory to `dist`.
